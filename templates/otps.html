One-time codes

Short numeric codes tied to a type and an identifier — password resets, email and phone verification. Checking one is POST /v1/otp/validate with all three fields; a correct code is spent the instant it is accepted.

The attempt ceiling is the security here. Six digits is a million possibilities, which a script exhausts quickly — so every wrong guess counts against the code, and it dies when the count runs out. Issuing again for the same identifier while a code is still alive returns that same code, so a "resend" button never leaves somebody holding two.
